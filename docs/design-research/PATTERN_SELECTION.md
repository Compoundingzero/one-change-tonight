# Pattern selection

The scorecard evaluates patterns against the actual context, not generic visual appeal. Each dimension is 1 (poor) to 5 (excellent); 35 is the maximum. A pattern is adopted when it improves rapid nighttime use without increasing diagnosis, privacy or accessibility risk.

## Adopt

- First question in the first viewport.
- One primary action per screen with explicit Continue.
- Experiment as the strongest output component.
- Visible local-only privacy and deletion.
- Native answer semantics, preserved Back and non-color selection.
- Progressive result depth after the useful action.
- Static direct answers with stable anchors and contextual tool entry.
- A short three-night sequence instead of a persistent dashboard.

## Adapt carefully

- Live model feedback: show selected clues and a quiet four-part framework, never a score or animated diagnostic gauge.
- Empty-state coaching: use one optional “why this matters” sentence, not arrows or tutorial overlays.
- Desktop whitespace: use it to protect focus, not to add an inspector or unrelated cards.
- Optional completion actions: print and private return are appropriate; social sharing is not.

## Reject

Pre-task onboarding, upload/drop metaphors, infinite canvas, persistent directory, three-pane editor, tabs for primary content, mascot-led branding, bright gradients, expert controls, donation/pricing modules, public share-by-default, streaks and diagnostic metrics.

## Palette candidates

1. **Quiet paper + deep teal (selected):** `#f7f4ed` paper, `#182321` ink, `#215f68` action, `#d9eceb` selected surface, `#f1e3d2` care surface. Mature, printable and distinct from pink/purple menopause branding. Night mode uses `#0e1718`, `#edf4ef` and `#89cbd1`.
2. **Clay editorial:** warm white, oxblood action, moss support and pale clay callouts. Rejected because oxblood can read as danger/blood in a symptom context and becomes harder to keep calm in low brightness.
3. **Midnight navy + lichen:** cool cream, navy ink, lichen action and fog surfaces. Rejected because it approaches hospital/enterprise blue and makes warm care notices less distinct.

Final contrast ratios remain a programmatic QA responsibility. The selected palette is the only candidate implemented, with high-contrast focus colors in both modes and no remote font dependency.

## Typography and motion

Use a system UI sans-serif stack for fast rendering, stable layout and legible controls. Strong weight and restrained scale create hierarchy; no proprietary reference pairing is copied. Motion is 130–190 ms, limited to state clarification, and collapses under `prefers-reduced-motion`.

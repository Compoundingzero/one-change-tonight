# Owner-only actions

| Owner action                                                                        | Why Codex cannot choose it                                                                |
| ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Select and control the final production domain                                      | Domain ownership and DNS authority belong to the owner.                                   |
| Provide legal owner identity and jurisdiction                                       | These are legal facts that must not be invented.                                          |
| Provide the monitored public contact email                                          | The owner must control and monitor the address.                                           |
| Verify Google Search Console and Bing Webmaster Tools                               | Verification requires owner-controlled accounts or DNS/site tokens.                       |
| Decide whether GPTBot training crawl is allowed                                     | This is an owner policy choice; OAI-SearchBot remains separately crawlable in production. |
| Appoint an identified qualified reviewer if a “medically reviewed” label is desired | Credentials and review completion cannot be fabricated.                                   |
| Approve any future analytics and legal basis                                        | The current release intentionally sends no analytics.                                     |

# Claim policy

Claims are classified as medical fact, environmental mechanism, product/manufacturer specification, editorial interpretation, or direct interface behavior. The visible copy must not imply a stronger class than its evidence supports.

- Medical fact: authoritative external source required; population and uncertainty preserved.
- Environmental mechanism: peer-reviewed or authoritative source; no treatment inference.
- Product claim: manufacturer label plus independent corroboration status; no ranking without a documented test.
- Editorial interpretation: explicitly framed as a rule, hypothesis, observation protocol, or experiment.
- Interface behavior: must match code and automated privacy/accessibility checks.

Prohibited without exact, scoped support include diagnosis, cure, prevention, treatment, “clinically proven,” “guaranteed,” “expert-approved,” and “medically reviewed.” The validator blocks a core phrase set; editorial review handles meaning that a string rule cannot detect.

# Product plan

## Release 0.1 — implemented

- Deterministic assessment with whole-room, bed-build-up, sudden-personal-heat, and mixed/uncertain outcomes.
- Moisture, one-sided partner need, failed-fix, frequent-disruption, and new/worsening modifiers.
- Seven reversible one-variable experiments, “Do Not Buy Yet” logic, three-night local tracking, printing, deletion, and low-brightness mode.
- Awake-and-hot shortcut, 24 substantial search pages, core pattern/comparison/evidence/trust pages, and 10 original diagrams.
- Static SEO shell, preview safeguards, validation scripts, CI, portable hosting config, and Railway preview deployment.

## Evidence-dependent follow-up

- Conduct moderated comprehension and usability sessions; the two-minute target is an engineering estimate until measured with people.
- Commission an identified qualified medical reviewer before using a medical-review label.
- Use Search Console and Bing impressions to improve existing pages before adding new pages.
- Evaluate any analytics proposal against the data-minimization policy before enabling it.
- Compare product mechanisms only after a documented, independent testing method exists; do not add rankings by default.
